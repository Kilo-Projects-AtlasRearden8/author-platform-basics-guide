# Author Platform Basics Guide

A free, privacy-safe, step-by-step manual for building an author platform with **zero ad budget**. Written for beginners — plain English, never condescending, tested locally.

This guide covers:

- Author bio (short, medium, long versions)
- Press release (template + free distribution)
- Newsletter setup (free tools, double opt-in, privacy-safe list building)
- Social posts (templates, cadence, repurposing)
- ARC readers (recruiting, distributing, FTC disclosure)
- Reviews (ethical asking, where they matter, responding)
- Local events (libraries, bookstores, virtual events, checklist)

Each chapter includes fill-in-the-blank templates you can copy and use immediately.

## How to use

1. Read `docs/README.md` for the full manual, or open `site/index.html` in your browser.
2. Copy a template from `docs/templates/` and fill in your book details.
3. Follow each chapter step by step. No ad budget is assumed anywhere.
4. Run `python3 scripts/verify.py` to check the site and docs are internally consistent.

## Privacy

This guide is privacy-safe by design:

- No home addresses, phone numbers, or personal emails in templates — use placeholders like `[your-email@example.com]`.
- No buying email lists or scraping reader data.
- Newsletter setup uses double opt-in and explains basic data-minimization habits.
- Local-event sign-in sheets collect only what you need.
